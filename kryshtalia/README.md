# Кристалія — Останній склад

Логічна гра у стилі Sokoban: проведіть персонажа до кристалів і заштовхайте
кожен кристал на рунічну підставку у сховищі. Кристал блимає, доки стоїть не на
своєму місці, і заспокоюється, щойно його встановлено.

## Запуск

Гра не потребує встановлення чи збірки — достатньо відкрити `index.html`
у браузері. Для зручності можна запустити локальний сервер:

```bash
cd sokoban
python3 -m http.server 8000
```

Потім відкрийте <http://127.0.0.1:8000/>.

## Керування

| Дія | Клавіші |
| --- | --- |
| Рух | стрілки або `W` `A` `S` `D` |
| Скасувати крок | `Z` або `Backspace` |
| Почати рівень заново | `R` |
| Вибір рівня | `L` |
| Довідка | `H` або `?` |
| Звук | `M` |

На мобільних пристроях працюють екранний D-pad і свайпи по полю.

## Можливості

- 10 рівнів з окремими кімнатами-сховищами.
- Анімований персонаж зі спрайт-листа: хода, поворот, поштовх кристала.
- Кристали блимають, доки не опиняться на своїх місцях.
- Таймер, лічильник кроків і поштовхів, рекорди та розблокування рівнів.
- Збереження прогресу в `localStorage`, звук через WebAudio.
- Повністю офлайн: HTML, CSS і JavaScript без зовнішніх залежностей.

## Файли

- `index.html` — розмітка інтерфейсу та модальні вікна.
- `styles.css` — тема, адаптивність, D-pad.
- `levels.js` — опис 10 рівнів.
- `game.js` — логіка гри, Canvas-рендеринг, анімації, звук і ввід.
- `images/diamond.png` — спрайт кристала.
- `images/spritesheet.png` — спрайт-лист персонажа (2 ряди × 6 кадрів, 128×256).
