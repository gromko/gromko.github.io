# Котигорошко — лабіринт-головоломка

Кулька-смайлик котиться лабіринтом, доки не вдариться об стіну. Зберіть усі блакитні кристали, щоб пройти рівень. У грі 20 рівнів, які генеруються детерміновано.

## Керування

| Дія | Клавіші |
| --- | --- |
| Рух | стрілки, `WASD`, свайп по полю або кнопки внизу |
| Крок назад | `Z` або `Backspace` |
| Почати спочатку | `R` |
| Наступний рівень після перемоги | `Enter` |
| Закрити вікно | `Esc` |

## Файли

- `index.html` — розмітка інтерфейсу.
- `styles.css` — тема, анімації, адаптивність.
- `app.js` — логіка гри, ввід, таймер, прогрес, звук.
- `maze.js` — генератор рівнів і BFS-перевірка розв'язності.
- `kotyhoroshko.html` — усе в одному файлі.

## Як це працює

- Рівні генеруються детерміновано (mulberry32), тому однакові для всіх.
- Розв'язність перевіряється пошуком у ширину по станах `(позиція кульки + маска зібраних скарбів)`.
- Прогрес, рекорди та налаштування звуку зберігаються в `localStorage`.
- Залежностей немає: тільки HTML, CSS і JavaScript.
