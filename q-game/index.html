Правила

Як грати в Q-GAME

1. Обери кулю

Клікни або торкнись кулі. Навколо неї з'явиться світле кільце.

2. Дай напрямок

Стрілки, WASD, свайп або клік по клітинці. Куля ковзає, доки не зустріне стіну, іншу кулю чи лузу.

3. Закоти в лузу

Підходить лише луза свого кольору. Луза іншого кольору працює як стіна.

4. Очисти поле

Коли на полі не залишиться жодної кулі, рівень пройдено. Можна грати далі або покращити рекорд.
